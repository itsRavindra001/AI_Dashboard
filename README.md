# AI Dashboard

A professional AI/ML-based live desktop dashboard designed to combine
system monitoring, productivity, learning progress, and future AI/ML
capabilities in a single Windows desktop application.

## Project Status

🚧 Early Development

## Planned Features

- Live clock and date
- System resource monitoring
- CPU, RAM, storage, and GPU information
- Weather information
- Learning progress tracking
- Focus timer
- Productivity shortcuts
- AI/ML integration
- Modern desktop interface
